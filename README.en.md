### What is it?

The mod corrects a long-standing mistake of vanilla Minecraft: the stonecutter block does not cause any damage, although visually it has a rotating blade. When a player or any mob steps on a stonecutter, it takes damage - exactly how it should have worked from the very beginning.

*What does this mod do?:*
- *Restores the missing damage from the stonecutter.*
- *Works on players and all types of mobs (passive, hostile, etc.).*
- *No additional features, no bells and whistles - just a fix.*

The mod is lightweight and safe to add to existing mod packs. No configuration is required, it works out of the box.

---

### How does it work?

The mod simply activates a hidden code that is already in the game. No complicated changes or additional libraries.

### 📥 How to install

1. Download and install Forge, Fabric or NeoForge for your version of the game.
2. For Fabric, download and install the Fabric API.
3. Download the mod file for your downloader and the game version from the [Releases] section (https://github.com/jfd-jgd/Stonecutter-Damage-Fix/releases ).
4. Copy without unpacking.jar file to the mods folder (it is located in the .minecraft directory).
5. Done! The mod is working.
